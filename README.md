# Pruthvi's DotFiles

## Dependencies

### MacOS
- Install Homebrew
- CLI: `brew install chezmoi starship git fzf ripgrep bat fd tmux git-delta wget mise lazygit neovim`
- GUI: `brew install --cask vivaldi ghostty iina wezterm`
- WM: `brew install aerospace && brew install nikitabobko/tap/aerospace FelixKratz/formulae/borders`
